# data-analytics-python
Мой опыт в аналитике данных, используя Python. Проводил разведочный анализ (EDA) в Python (pandas, numpy), выявлял аномалии и закономерности, визуализировал результаты с помощью matplotlib и seaborn.

Аналитические компетенции:

- Анализ пользовательской активности и динамики выручки по периодам.
- Расчёт среднего чека, жизненной ценности клиента (LTR) и длительности жизненного цикла (LT).
- Определение влияния маркетинговых акций на поведение клиентов и финансовые результаты.
- Сегментация пользователей по городам и возрастным группам, выявление различий в поведении.
- Проведение когортного анализа для оценки удержания клиентов.
- Работа с выбросами и интерпретация аномальных значений в данных.
- Формулирование бизнес-выводов и подготовка рекомендаций на основе анализа данных.

Инструменты и приёмы работы с Python:

- Использование библиотек pandas, numpy, matplotlib, seaborn для анализа и визуализации данных.
- Очистка и предобработка данных: проверка пропусков, фильтрация, преобразование типов.
- Агрегация и группировка данных, расчёт пользовательских метрик и показателей.
- Создание функций для автоматизации аналитических расчётов.
- Проведение когортного анализа и построение графиков удержания клиентов.
